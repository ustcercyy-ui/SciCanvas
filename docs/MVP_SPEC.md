# SciCanvas MVP 产品规格

版本：0.1  
状态：开发基线  
目标平台：Windows 10 22H2、Windows 11  
默认语言：简体中文（架构预留本地化）

## 1. 产品定义

SciCanvas 是一款在本地运行的科研图像裁剪与组图软件。它解决以下主问题：

> 从多张尺寸不同的科研图片中，以完全相同的像素宽高选取不同位置的区域，再将结果准确排列为论文组图，同时保护源文件并记录全部操作。

MVP 的成功标准不是功能数量，而是完成一条可信闭环：

1. 导入源图像并识别尺寸、位深和元数据。
2. 从任意图像创建固定像素裁剪模板。
3. 在后续图像上复用同一尺寸并自由移动裁剪位置。
4. 将裁剪结果作为非破坏图层加入拼版画布。
5. 使用对齐、分布和图层工具完成组图。
6. 保存可恢复、可审计的工程文件。
7. 从原始像素重新渲染并导出新文件。

## 2. 目标用户

### 2.1 主要用户

- 材料、化学、物理、生物材料和能源方向研究人员。
- 经常处理 SEM、TEM、荧光、明场、凝胶、Western blot 和常规仪器导出图像的研究人员。
- 需要将多张实验图裁剪为统一尺寸并组装论文图的学生和科研助理。

### 2.2 用户的核心顾虑

- 担心裁剪或导出时覆盖原始数据。
- 担心软件在不知情的情况下缩放、插值或降位深。
- 担心不同面板尺寸、间距、字体和比例尺不一致。
- 担心投稿时无法说明图片如何处理。
- 不希望为了简单组图学习完整的商业图像编辑软件。

## 3. 产品原则

### 3.1 原图不可变

- 所有源文件只能通过只读接口访问。
- 软件没有“保存到源文件”命令。
- 裁剪、摆放、显示调整、文字和比例尺均保存为工程操作。
- 导出始终创建派生文件。

### 3.2 像素含义明确

- 源图像坐标、画布世界坐标和屏幕坐标严格分离。
- 裁剪矩形只允许使用源图像整数像素坐标。
- 画布缩放不改变裁剪坐标。
- 缩放和裁剪是两个不同命令。

### 3.3 显式转换

任何可能改变数据的操作都必须显式显示并进入操作记录，包括：

- 尺寸缩放。
- 插值方式。
- 旋转（90°倍数除外也需要记录）。
- 位深转换。
- 颜色空间转换。
- 亮度、对比度、Gamma、伪彩色或通道映射。

### 3.4 最终导出来自原始数据

画布可使用缩略图或分块代理提高速度，但最终导出必须重新读取源文件相应区域，不得导出屏幕截图或预览缓存。

## 4. MVP 范围

### 4.1 P0：必须完成

#### 文件与元数据

- 导入 PNG、JPEG、BMP、8/16-bit 灰度或 RGB TIFF。
- 显示文件名、完整路径、像素宽高、通道数、位深、DPI、文件大小和颜色配置摘要。
- 可识别 TIFF 中常见的物理分辨率；无法识别时明确显示“未提供”。
- 为源文件计算 SHA-256 指纹并保存文件大小、最后修改时间和可选 Windows File ID。
- 导入后显示“源文件只读保护”。

#### 固定尺寸裁剪

- 自由绘制裁剪区域。
- 输入精确的 X、Y、宽、高。
- 将当前宽高保存为裁剪模板。
- 在其他源图像上套用裁剪模板并保持宽高锁定。
- 使用鼠标拖动裁剪区域。
- 方向键移动 1 px；Shift + 方向键移动 10 px。
- 裁剪区域越界时阻止确认，并显示需要修正的边界。
- 画布以 100% 显示时支持最近邻像素预览。

#### 拼版画布

- 裁剪结果作为独立图层加入画布。
- 图层可移动、显示/隐藏、锁定、重命名、排序和删除。
- 支持多选。
- 左对齐、水平居中、右对齐、顶对齐、垂直居中、底对齐。
- 水平等距、垂直等距，支持输入精确间距。
- 支持透明、白色或黑色画布背景。
- 支持输入画布像素宽高。
- 支持吸附到画布边缘、参考线和其他图层边缘。

#### 基础论文标注

- 添加文本图层。
- 添加箭头、矩形和椭圆轮廓标注，使用画布像素坐标与物理线宽。
- 快速生成 a、b、c 或 A、B、C 面板标签。
- 添加基于图像物理比例的比例尺；缺少物理比例时禁止伪造并要求用户明确输入校准值。
- 文本、比例尺与图像分层存储。

#### 工程与历史

- 新建、保存、另存为和打开 `*.scicanvas` 工程。
- 撤销/重做至少保留最近 100 个命令。
- 自动保存恢复文件。
- 工程打开时验证源文件指纹。
- 源文件丢失或发生变化时进入“重新链接/确认新版本”流程，不静默替换。

#### 模板

- 期刊尺寸预设：Nature 类单栏/双栏、Advanced Materials 类单栏/双栏、自定义。
- 通用 2×2 网格。
- 1 个主面板 + 4 个支持面板。
- 多尺度形貌表征。
- 制备—结构—性能证据链。
- 时间序列。
- 多条件对照矩阵。
- 模板只定义布局语法和规则，不包含论文中的受版权保护图片。

#### 导出

- PNG：8-bit 灰度/RGB/RGBA。
- TIFF：保留可支持的 8/16-bit 灰度或 RGB 数据。
- 可选择按画布原始像素导出或明确指定缩放尺寸。
- 发生缩放时必须选择插值方式。
- 可导出 JSON 操作报告。
- 默认文件名追加 `_export`，不得默认覆盖任何已有文件。
- 导出前执行源路径冲突检查。

### 4.2 P1：MVP 后的第一个增量

- 多页 TIFF。
- OME-TIFF 元数据和导出。
- SVG/PDF 中的可编辑文字、形状和曲线图层。
- 亮度、对比度、Gamma、通道和伪彩色的非破坏调整。
- 图像完整性检查：重复区域、非等比拉伸、低分辨率、缺失比例尺。
- 12 套完整材料领域模板。
- 批量导出和命令行模式。

### 4.3 明确不属于 MVP

- AI 识别目标或自动美化。
- 自动特征配准和全景拼接。
- 厂商专有显微镜格式的全面读取。
- DICOM、三维体数据、Z-stack 和时间序列播放。
- 数据曲线绘制和统计分析。
- 云同步、多人协作或在线账户。
- Python/R 插件系统。

## 5. 主界面规格

视觉基线见 [已选主界面方向](assets/scicanvas-selected-ui.png)。

### 5.1 顶部命令区

- 打开源图像。
- 保存工程、另存工程。
- 撤销、重做。
- 裁剪、移动、缩放、适合窗口。
- 网格、标尺、参考线。
- 拼版视图、添加到拼版、导出拼版。

“保存工程”与“导出结果”必须使用不同图标、命令名称和快捷键，避免用户误以为会保存回源图。

### 5.2 左侧源图像区

- 缩略图、文件名、尺寸和位深。
- 当前图像高亮。
- 每个源图显示只读锁状态。
- 支持搜索、筛选和按导入顺序排序。
- 右键菜单不提供移动、删除或改写磁盘文件的操作。
- 从工程移除只删除工程引用，不删除文件。

### 5.3 中央工作区

- 显示源图或拼版画布。
- 标尺单位可切换 px、mm、µm；裁剪编辑默认 px。
- 裁剪框显示宽 × 高。
- 可开启十字中心线和三分线。
- 低于 100% 时使用高质量预览；100%及以上可切换像素网格。

### 5.4 右侧检查器

按以下顺序组织为可折叠区域：

1. 源图像信息和“源文件只读保护”。
2. 裁剪 X、Y、宽、高。
3. 对齐与分布。
4. 图层列表。
5. 精确画布位置和尺寸。

图层行至少包含：可见性、缩略图、名称、锁定、上移/下移。

### 5.5 底部状态栏

- 缩放倍率。
- 光标的源图像像素坐标。
- 光标采样值。
- 当前图像尺寸和位深。
- “无损编辑 · 原图未修改”。
- 工程文件名和自动保存状态。

## 6. 关键用户故事与验收标准

### US-01：创建参考裁剪尺寸

作为研究人员，我希望在第一张图上定义 `1200 × 800 px` 的区域，以便后续图片复用相同尺寸。

验收：

- 输入宽高后裁剪框立即更新。
- 保存为模板后，模板包含名称、宽、高和单位。
- 不保存第一张图的 X、Y 作为其他图片的默认位置，除非用户明确选择“同时复制位置”。

### US-02：在下一张图上移动同尺寸裁剪框

验收：

- 应用模板后宽高保持锁定。
- 鼠标拖动只改变 X、Y。
- 方向键每次恰好改变一个源像素。
- 在任意 DPI 缩放下确认后坐标一致。

### US-03：加入拼版并精确对齐

验收：

- 加入拼版不会创建修改后的源文件。
- 多选图层可以按边缘或中心对齐。
- 输入 `24 px` 水平间距后，相邻图层边界距离恰好为 24 个画布像素。
- 撤销可恢复对齐前的位置。

### US-04：保护源文件

验收：

- 导入、裁剪、保存工程、自动保存、导出、崩溃恢复后，源文件 SHA-256 均保持不变。
- “导出为”选择源文件自身或其硬链接时，操作被阻止。
- 从源图像列表移除项目不会删除磁盘文件。
- 源文件被外部修改时，软件提示差异且不自动接受新内容。

### US-05：保存并恢复工程

验收：

- 重新打开工程后，源引用、裁剪坐标、图层顺序、画布位置、标签和模板均一致。
- 若源文件位置变化但哈希一致，用户可重新链接。
- 若哈希不同，必须显示“源文件版本已改变”。

### US-06：按期刊尺寸导出

验收：

- 选择预设后显示毫米尺寸、像素尺寸和当前 DPI 的对应关系。
- 字号、分辨率或画布高度不符合预设时给出警告而不是暗中修改。
- 导出的操作报告记录预设 ID 和版本。

## 7. 非功能需求

### 7.1 准确性

- 纯裁剪导出时，输出像素数组必须与源文件指定矩形逐值一致。
- 所有裁剪边界使用 64-bit 整数，避免大图溢出。
- 16-bit 数据不得因预览而降为 8-bit 后导出。

### 7.2 性能目标

- 本地 SSD 上，20 MP PNG/JPEG/TIFF 的首个可交互预览目标不超过 2 秒。
- 已缓存区域平移和缩放目标达到 30 FPS。
- 100 个源图像、50 个拼版图层的工程仍可交互。
- 导出任务支持进度、取消和失败恢复，不阻塞界面线程。

### 7.3 稳定性

- 编辑停止 10 秒后自动保存一次，仅保存工程状态，不复制或改写源图。
- 导出采用临时目标 + 原子重命名，失败时不得留下被误认为完整结果的文件。
- 崩溃恢复文件与用户主动保存的工程分离。

### 7.4 隐私

- 默认不联网。
- 不上传源图、缩略图、工程路径或操作记录。
- 更新检查必须可关闭，并且只请求版本信息。

### 7.5 可访问性

- 支持键盘完成核心流程。
- 颜色不是唯一状态表达方式。
- 深色主题保持足够对比度。
- 支持 Windows 125%–250% 显示缩放。

## 8. 快捷键基线

| 操作 | 快捷键 |
|---|---|
| 打开源图像 | Ctrl+O |
| 保存工程 | Ctrl+S |
| 工程另存为 | Ctrl+Shift+S |
| 撤销/重做 | Ctrl+Z / Ctrl+Y |
| 裁剪工具 | C |
| 移动工具 | V 或 Space 暂时切换 |
| 适合窗口 | Ctrl+0 |
| 100%显示 | Ctrl+1 |
| 添加到拼版 | Ctrl+Enter |
| 锁定图层 | Ctrl+L |
| 导出 | Ctrl+Alt+E |

快捷键不得复用为任何“覆盖源文件”行为。

## 9. 发布范围与开发估算

加入图层、模板与源保护后，单人全职开发的现实 MVP 周期建议按 7–10 周规划：

1. 基础工程、文档模型和只读导入：1 周。
2. 元数据、缩略图和分块预览：1 周。
3. 精确裁剪与坐标系统：1–1.5 周。
4. 拼版、图层、对齐与撤销：2 周。
5. 工程保存、源验证和自动恢复：1 周。
6. 导出与初始模板：1–1.5 周。
7. 像素回归测试、DPI测试、安装包和修复：1–2 周。
